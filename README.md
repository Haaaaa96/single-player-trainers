## 怎么下载

打开对应游戏的下载页，在 **Assets** 中选择明确标注的修改器 ZIP。README 已放在分享包内。

**不要下载 GitHub 自动生成的 “Source code (zip/tar.gz)” 来安装修改器**：它们只是本仓库说明文件的快照。

不同游戏有各自的版本，不要用仓库统一的 Latest 标记判断某一游戏是否最新。上表始终指向各游戏对应下载页。
