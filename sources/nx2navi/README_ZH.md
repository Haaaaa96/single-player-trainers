# NX2naviTrainer v0.1.1

简体中文游戏内修改器的源码快照。基于 Windows x64 版 [NX2navi v0.6.1](https://github.com/tangerineturtle1/NX2navi/releases/tag/v0.6.1)，适配 Nintendo Switch 2 版《塞尔达传说：时之笛》1.1.1。

所需输入、构建及安装见[构建说明](BUILD_ZH.md)，上游条款见[第三方声明](THIRD_PARTY_NOTICES.md)。发布包包含修改器代码、构建脚本、文档和必要声明。游戏数据和 NX2navi 构建工具需在本机准备，EXE 在本机生成。
