# NX2naviTrainer v0.1.1

Source snapshot of a Simplified Chinese in-game trainer for [NX2navi v0.6.1](https://github.com/tangerineturtle1/NX2navi/releases/tag/v0.6.1) on Windows x64, targeting the Nintendo Switch 2 edition of The Legend of Zelda: Ocarina of Time v1.1.1.

See [BUILD.md](BUILD.md) for required inputs, build and installation. [Third-party notices](THIRD_PARTY_NOTICES.md) describe the applicable upstream terms. The snapshot contains only the trainer code and recipe, plus documentation and required notices. Game data, NX2navi source and the linked executable are supplied through the local build process.
