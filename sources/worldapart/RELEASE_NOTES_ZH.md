# WorldApartTrainer v1.3 研究快照

[English](RELEASE_NOTES.md) | 简体中文

本源码记录v1.3 `read-performance-1`研究阶段，参考环境为Windows x64、Steam build 25617557。
实现范围涉及人物数值、背包与货币、当前资源、功法与疏经、炼丹炼器、双修、刮玉、说服及留影。

读取优化针对资质、功法与留影页面的首次读取。历史验证区分只读结果、离线保护与先前用户反馈，
不能据此认定每项实机写入、结算、存读档及全新后台启动均在该阶段验证。

本公开副本排除了两份游戏派生配置，并移除旧个人展示标签，不是完整可运行发行包。
源码及测试的缺失输入、构建边界见[构建说明](BUILD_ZH.md)。

游戏版本及文件差异仅作提示，实际对象身份、字段类型、方法签名和操作条件决定操作是否允许。
不得绕过保护；派发或结果不明时不得盲目重试。以后开展获准的实机实验前应备份存档。
