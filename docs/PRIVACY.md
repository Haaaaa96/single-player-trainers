# Privacy and provenance

## What is exported

The source directories are selected snapshots. Personal path defaults, machine identifiers and former display bylines are removed or replaced in the public copies where identified. Build parameters describe local inputs without exposing the original machine layout. The original private working directories are not published.

Private Git history, raw conversations, internal task records, save files, runtime logs, session state, credentials, browser data and personal configuration are excluded. Development logs are rewritten summaries of engineering findings, not uploads of internal reports.

## Limits

This repository intentionally remains under its existing GitHub account. The owner, platform-generated commit identity and previous public history remain visible; this is content de-identification, not identity anonymity. Historical release files retain their original bytes and may contain earlier display names or wording. No history rewrite or binary rebuild is implied.

Required third-party attribution is preserved in license files even where it includes an upstream name or email. It is a legal provenance record, not a contact or acknowledgement section.

## Reproducibility

Each source export includes a file manifest. It identifies the public copy, not a promise that the copy generates a bit-identical historical executable. Build notes list missing game-specific resources and dependencies. Existing release hashes continue to identify the original artifacts separately.

Privacy review and static checks are not a security certification. No claim about an unrelated downloaded file or antivirus alert follows from a source snapshot.
