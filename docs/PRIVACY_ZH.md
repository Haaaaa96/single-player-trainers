# 隐私与来源边界

## 公开范围

源码目录是经过选择的快照。已识别的个人路径默认值、机器标识及旧显示署名，在公开副本中删除或替换。构建参数描述所需本地输入，不公开原电脑目录结构；私人工作目录不直接上传。

私人 Git 历史、原始对话、内部任务记录、存档、运行日志、会话状态、凭据、浏览器数据和个人配置均排除。开发记录重新整理为工程结论，不直接上传内部报告。

## 边界

本仓库继续使用现有 GitHub 账号。仓库所有者、平台生成的提交身份及既有公开历史仍可见；这是内容脱敏，不是身份匿名。历史成品附件保留原字节，可能含早期署名或文案，本次不隐含重写历史或重新构建程序。

第三方许可证需要保留原作者姓名或邮箱时，原文保留。它们属于许可来源记录，不是联系或致谢板块。

## 可复现范围

每份源码导出包含文件清单，用于识别公开副本，不保证能生成与历史程序逐字节相同的文件。构建说明列出缺少的游戏相关资源和依赖；既有成品哈希继续独立标识原附件。

隐私审查和静态检查不构成安全认证；不能据此判断其他来源的下载文件或安全软件告警。
