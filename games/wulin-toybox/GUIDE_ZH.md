对应2026-09-30记录的插件更新包：游戏V1.2.0818 75 / Steam Build 24794582，Windows 11 x64。工具界面仍为中文。

## 安装插件更新包

1. 正常退出游戏，备份存档和原HaxxToyBox.dll。
2. 尚无原前置环境时，从[原整合帖](https://bbs.3dmgame.com/thread-6489560-1-1.html)取得并按其说明安装。本包不是完整加载器包。
3. 核对BepInEx/plugins/HaxxToyBox/UniverseLib.IL2CPP.dll、原AssetBundle、加载器等必要文件，不混用不同代际框架。
4. 将本包BepInEx目录合并到Wulin.exe所在目录，只替换同位置HaxxToyBox.dll；保留前置及其它MOD，不清空目录，不保留重复插件。
5. 启动并读档，按Tab，左下角应为HaxxToyBox v1.1.0。回退时先退出，再恢复备份DLL。

WulinToyBox-v1.1.0-plugin.zip不含BepInEx、.NET、UniverseLib、EnhanceGameplay或Unity库。武学上限扩展仍需原EnhanceGameplay模块，本包不另提供。

## 操作与输入

| 控件 | 用法 |
| --- | --- |
| Tab | 显示／隐藏 |
| F1 | 恢复 |
| =／− | 游戏加速／减速 |
| 改键 | 辅助页修改，录入时Esc取消 |
| 人物属性 | 编辑当前队伍角色基础值，回车提交；最终面板可能叠加装备、天赋 |
| 百分比 | 0～1小数，例如0.01 |
| 品性 | −100～100整数，其它字段按界面范围 |
| 物品 | 按名称跨分类搜索，确认目标，新增1～9999整数；清空词恢复分类 |
| 金钱 | 目标总额，单位“文”，0～999999999整数，回车提交 |
| 能力经验倍率 | 1～1000整数，回车提交；填1恢复正常 |

天赋支持搜索、添加和移除，避免重复添加。鼠标放在原武学列表内滚动，可使用前置排序和遗忘；“无限武学：由扩展模块处理”是说明文字，不需点击。移动速度拖动滑条手柄，游戏速度也可用快捷键；设为1倍恢复本修改器的正常速度。

送礼辅助需先开启“添加满好感按钮（送礼页面）”，再进入NPC送礼页点击“满好感”；仅开启开关不会修改全部NPC。

能力经验倍率只作用于新获得的对应能力经验，不是武学升级历练，也不会直接增加已有经验。能力满级后可能不再显示经验增长。

## 效果与限制

- 先备份并使用独立存档，核对效果后再保存。
- 历史实测覆盖时间暂停、不遇敌开关和一次普通遭遇的主角战后恢复；不遇敌不代表跳过所有剧情强制战斗。
- 队友、送礼和经验倍率保留自此前正常使用；v1.1.0重点检查主角属性、搜索、天赋、武学界面及辅助控制。
- 首启或游戏更新后初始化可能较慢，尚未彻底解决。若长期停在启动画面，保留生成文件，正常退出后尝试重启一次，不反复删缓存。
- “解锁成就”是永久操作，恢复存档不能撤销。首次点击后10秒内再次点击确认，离开辅助页或超时取消；历史检查未执行永久解锁。
