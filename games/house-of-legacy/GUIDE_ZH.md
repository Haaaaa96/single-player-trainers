# 《吾今有世家》v0.3.0 — 操作说明

历史参考环境：2026-10-01，游戏V0.9.03 / Steam Build 22970665，Windows x64、Unity Mono、BepInEx 5.4.23.5。压缩包包含HouseOfLegacyTrainer.dll（内部版本0.3.0.0）和README-v0.3.0.txt，不含游戏、存档、加载器、个人配置或日志；使用时不需要.NET SDK或Python。

## 安装或升级

1. 正常保存并退出游戏，备份整个存档目录。常见位置为%USERPROFILE%/AppData/LocalLow/S3Studio/House of Legacy，不要只备份GameData.es3。
2. 在Steam中选择“管理→浏览本地文件”，找到House of Legacy.exe。
3. 尚未安装框架时，将[BepInEx_win_x64_5.4.23.5.zip](https://github.com/BepInEx/BepInEx/releases/tag/v5.4.23.5)解压到游戏EXE同级，BepInEx、winhttp.dll和doorstop_config.ini应在该层。不要选x86、IL2CPP或BepInEx 6；已有MOD加载器时先核对，不直接混装，保留框架文件与许可。
4. 将HouseOfLegacyTrainer.dll放入BepInEx/plugins/HouseOfLegacyTrainer。升级前把旧DLL及配置备份到游戏目录外，再替换原位置文件；plugins下不要留多份版本。
5. 启动并读档，在正常游戏或原人物页按Tab。

受保护安装目录复制文件时可能需要Windows授权。核对实际安装位置，不修改整个目录权限，也无需日常强制管理员运行游戏。

## 基本操作

开窗自动暂停。选功能后先刷新，核对人物姓名、ID、当前值和输入含义，再应用。原人物页仍为同一人物且身份检查通过时会同步刷新，否则关窗重开人物页核对。

按Tab或“关闭”，松开键鼠后继续。关窗恢复原有运行／暂停及速度状态。通过游戏原菜单保存才能保留改值；插件不自动保存，关窗或停用不会撤销改值。

默认左侧布局已检查1280×720和1920×1080，超出内容可滚动。自动化检查未见标题栏拖动位移，手动拖动仍待确认。文本框内Tab也用于关窗，请用鼠标选输入框。开窗时隔离游戏点击、滚轮和快捷键；切出游戏会关窗并恢复原状态，切回后先松键再开窗。

## 输入范围：14项单次操作

| 操作 | 输入 |
| --- | --- |
| 铜钱 | 非零整数变化量，−1,000,000～1,000,000，不能扣成负余额 |
| 家族声望 | 新增量1～本级剩余声望，单次最多升一级，保留原游戏资金条件和升级联动 |
| 文才、武才、商才、艺才、声名 | 目标0～100，可用小数 |
| 心情 | 整数目标−100～100 |
| 健康 | 整数目标1～100，不代表治病、延寿或永生 |
| 魅力、心机 | 整数目标0～100 |
| 体力 | 单次恢复按钮，目标依年龄和当前状态确定 |
| 开局特质剩余点数 | 整数目标0～1000，仅特质选择页生效；通过原游戏选择特质并确认角色 |
| 已有蔬菜 | 新增1～1000且不超过剩余容量，数量与剩余库容同步变化 |

人物属性仅针对当前选定本族成员。开局点数不改已有角色特质，蔬菜功能不能生成未持有物品。目标值是替换，铜钱填变化量。原人物页部分值向下取整；顶部铜钱／声望可能需关窗恢复后更新，先看读回，不要重复提交。

应用、换档、换人、换场景、数据变化或等待较久后重新刷新。加载、保存、切场景、交易时先等待。结果不明时先核对，不连续重试。所有功能都不持续锁定，成长、消耗和事件仍会发生。

## 改键、停用和回退

退出后编辑BepInEx/config/local.houseoflegacy.trainer.cfg的ToggleKey，下次启动生效。旧默认F8配置会迁移为Tab，其它自定义键保留，无需修改HotkeySchema。原游戏Tab也用于建造／编辑，可改游戏按键或插件开关键。

停用时正常退出，将BepInEx/plugins/HouseOfLegacyTrainer整个文件夹移到游戏目录外，仅在plugins内改名无效；放回可恢复。回退时退出后放回旧DLL及对应配置，v0.2.0使用先Esc、再F8。回退插件不撤销已保存进度。不要运行中替换DLL，也不要删除其它MOD或整套加载器。

没有窗口时核对加载器版本、DLL位置、当前场景及配置键。BepInEx/LogOutput.log记录加载和拒绝原因，可查找HouseOfLegacyTrainer 0.3.0。若未生成配置／日志，先查加载器，不反复复制插件，不同时安装不同包中的重复DLL。

[开发记录](DEVLOG_ZH.md)区分历史验证与未测字段、状态边界和MOD组合。版本／文件差异仅作提醒，实际结构不兼容或输入保护无法初始化时，相应操作会停止。

## 许可

插件独立编写，运行时引用游戏／BepInEx组件，不内嵌第三方DLL。保留依赖项目原有许可。
