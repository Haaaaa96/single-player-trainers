# HookshotTrainer 0.2.25-dev

适用于 Switch 2 版《塞尔达传说：时之笛》1.1.1 和 Windows x64 版 Hookshot v2.3.1。归档提供修改器源码和本地构建脚本，游戏代码、资源及运行组件由使用者自己的对应版本提供。

按键盘反引号键打开中文面板。「主线」显示任务进度与迷宫指引。「常用」包含传送、地图指引、飞行以及弹药和魔力控制。「道具」可搜索目录、增删物品或装瓶。

0.2.25-dev 新增「删除空瓶」。每次删除一个空瓶，保留已有内容的瓶子，以及童年或成年道具栏已分配的瓶子。库存和持有标记两项读回都确认清除后，面板才显示成功。
