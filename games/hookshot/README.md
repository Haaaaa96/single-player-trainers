# HookshotTrainer 0.2.25-dev

An in-game Chinese trainer for the Nintendo Switch 2 version of *The Legend of Zelda: Ocarina of Time* v1.1.1, built with Hookshot v2.3.1 for Windows x64. The archive contains the trainer source and build scripts. A matching local game build supplies the game code, assets and runtime components.

Press the backtick key to open the panel. **主线** shows quest progress and dungeon guidance. **常用** includes teleportation, map guidance, flight, ammunition and magic controls. **道具** lets you search the catalog, add and remove items, or fill a bottle.

Version 0.2.25-dev adds removal of one empty bottle at a time. Bottles containing an item and bottles assigned to a child or adult item slot are preserved. The panel reports success after it reads back both the inventory count and the bottle ownership flag.
