## 使用方法

先备份存档，解压运行 WorldApartTrainer.exe，启动游戏并读档，点击“连接游戏”。游戏安装位置不限，可自动识别或手动选择 WorldApart.exe。选择功能页后先读取／刷新，再按提示操作。

“目标值”是修改后的数值；“新增数量”是本次增加量。灵石单次最多增减／新增1亿，总额最多999,999,999；游戏上限更低时从低。城镇、宗门贡献单次新增最多100万。其他范围见功能页。

## 操作提醒

- 数值、物品和留影操作请回到稳定普通场景；小游戏先正常进入对应对局。不要在战斗、转场或结算时修改普通数值和物品。
- 炼丹需先正常投料，再按游戏要求添加灵力；进入控火阶段后读取并使用辅助。
- 留影入口在清单上方。激活后回游戏找角色互动；强制重玩会清除所选阶段的成功记录，失败或退出不会自动恢复，成功后也可能再次发放奖励，请先看弹窗影响。
- 秒说服判定成功后，仍需等待游戏原有倒计时和结算。刮玉完整揭示不改变天然品质或裂纹，也不保证达到兑换门槛。
- 游戏可能自动保存；退出修改器不会恢复游戏速度，需要时先调回1倍。
- 未来更新可能使部分功能失效。版本或MOD文件差异不会直接拒绝连接，但实际结构不兼容时对应功能会停止。报错或结果不明时，先核对是否已生效，勿反复点击。
