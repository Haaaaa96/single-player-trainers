# NX2naviTrainer

为 [NX2navi v0.6.1](https://github.com/tangerineturtle1/NX2navi/releases/tag/v0.6.1) 制作的游戏内修改器。适配的是 **Nintendo Switch 2 版《塞尔达传说：时之笛》1.1.1**，Title ID 为 `0400486024DEC000`，主 NSO 的 Build ID 前缀为 `E0F3CCFAF50065AE`。NX2navi 将这个版本静态重编译为使用 Vulkan 的原生 Windows x64 程序。

读档后按 **Esc → 金手指**，可恢复生命、保持满血、在当前钱包容量内设置卢比、补充已解锁的弹药，或添加目录中符合条件的物品。修改器界面为简体中文，物品搜索支持中英文及内部名称。

- [v0.1.1 源码发布](https://github.com/Haaaaa96/single-player-trainers/releases/tag/nx2navi-v0.1.1)
- [运行环境、构建与安装](../../sources/nx2navi/BUILD_ZH.md)
- [开发与验证记录](DEVLOG_ZH.md)

发布包含修改器源码和本地构建脚本。使用前需用自己的对应版本游戏转储完成 NX2navi 构建，并保留构建缓存。成品使用 NX2navi 自己的运行环境，Cheat Engine 和 REA 仅用于研发。

本项目为个人研究归档，适用[仓库条款](../../TERMS.md)以及构建说明所列的上游和第三方条款。
