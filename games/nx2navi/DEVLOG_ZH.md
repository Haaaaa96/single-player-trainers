# NX2naviTrainer v0.1.1 开发记录

检查的 v0.6.1 运行时已经包含金手指面板代码，原版暂停菜单没有提供入口。本地构建脚本添加菜单入口，并接到已定位的玩家更新函数。修改器检查当前玩家和场景，写入后读回结果，道具添加则等待库存请求结果。「保持满血」在符合条件的更新中补回当前生命上限，玩家或场景身份变化时关闭。

从游戏注册数据读到 395 条目录记录，其中 96 条具备添加路径要求的库存与容量元数据，当前库存和进度仍可能限制添加。目录会展示不可添加的条目及原因。本机目录有 184 个中英双语名称，价值和占用未知的条目排在已知项之后。

本机使用隔离存档实测生命从 2.75 恢复至 3 颗心、保持满血开关、卢比从 7 改为 76、德库坚果棒从 2 补到 10、海利亚盾从 0 添加到 1。保存后重启复查了代表性数值，并验证正常退出。中文版还检查了中文显示、回车搜索、添加成功和库存已满提示。实测环境为 Windows 11 Pro x64 build 26200、Intel Core i7-13700K、GeForce RTX 4070 Ti。

发布版源码使用相同的本机 NX2navi 0.6.1 构建工具和游戏输入独立完成了编译，使用 Python 3.14.7 与随附 UCRT64 Clang 23.1.5。发布检查生成的 EXE 未启动，上述运行结果来自本机修改器构建。96 个候选物品未逐个实测，其它游戏版本或主机构建仍待验证。
