# NX2naviTrainer

An in-game trainer for [NX2navi v0.6.1](https://github.com/tangerineturtle1/NX2navi/releases/tag/v0.6.1), the native Windows recompilation of **The Legend of Zelda: Ocarina of Time (Nintendo Switch 2), v1.1.1**. It targets Title ID `0400486024DEC000`, main NSO Build ID prefix `E0F3CCFAF50065AE`. The supported runtime is the Windows x64 Vulkan build of NX2navi.

The **金手指** panel in the Esc menu lets you restore or maintain full health, set rupees within the current wallet limit, refill unlocked ammunition, and add supported items from the game catalog. Item search accepts English, Simplified Chinese and internal names. The trainer interface is in Simplified Chinese.

- [v0.1.1 source release](https://github.com/Haaaaa96/single-player-trainers/releases/tag/nx2navi-v0.1.1)
- [Runtime, build prerequisites and installation](../../sources/nx2navi/BUILD.md)
- [Development and verification record](DEVLOG.md)

The release contains trainer source and a local build recipe. It requires an existing NX2navi build made from your own matching game dump, with the build cache intact. The resulting program uses NX2navi's own runtime. Cheat Engine and REA were research tools and are optional for users.

This is a personal research archive. [Repository terms](../../TERMS.md) apply alongside the upstream and third-party terms linked in the build instructions.
