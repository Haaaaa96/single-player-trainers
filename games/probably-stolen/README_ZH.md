# 深空当铺：可能是偷的 多功能修改器 V1.9.4

本页记录《深空当铺：可能是偷的》原生 MOD 修改器的个人研究与开发结果。本次发布包含修改器二进制、使用说明和开发小记，**不包含实现源码**。

[版本与压缩包](https://github.com/Haaaaa96/single-player-trainers/releases/tag/probably-stolen-v1.9.4) · [安装与使用](GUIDE_ZH.md) · [开发小记](DEVLOG_ZH.md)

- 版本：**V1.9.4**；构建：`1.9.4-20261030a`；日期：2026-10-30。
- 参考游戏：Steam build `26284217`（2026-10-29）。
- 使用游戏原生 MOD 接口，无需额外安装加载器或框架。
- 默认 **F4** 打开/关闭菜单，可自定义并保存；**Esc** 也可关闭。

## 功能

1. **现金增加：**每次增加 1–10000000 信用点。
2. **物品目录：**默认显示当前已加载目录，支持分类、关键词/回车搜索和分页；显示参考单价与占用格数，支持价值、体积升降序；每次添加 1–100 份默认包装。
3. **目标库存补货：**按目标包装数量补足缺额，达到目标后不再增加。
4. **常用品收藏：**保存最多 12 项商品及目标数量，支持单项和批量补货。
5. **鉴定辅助：**悬停查看真实特征、赃物和违禁信息，不直接改变揭露状态。
6. **物品维护：**修复自有物品耐久、护甲，为符合条件的可充电电池充满，保留当前上限。
7. **交易辅助：**推算议价风险，恢复当前鉴定顾客尚未耗尽的耐心，查看与限定揭露柜台普通物品特征。
8. **库存删除：**删除主仓或后仓中选中的普通自有物品整组，不处理容器、特殊回调或危险废物。
9. **水管理：**六种水质、五种瓶桶规格，支持生成、补货、收藏，以及查看、补满、换水、排空、定量倒掉、净化、转移和标注纠正。
10. **机器装配：**生成并安装缺少的配件；基础补齐保留已有配件，推荐最强装配按机型强化并追加适用的非负加成普通模块，支持标准仓扩容和旧件退库；神经核心可选，默认关闭。
11. **顾客需求备货：**匹配自有商品，包含普通储藏槽内商品；支持手动勾选或高/低参考价值优先自动选货，整件/整堆移入购买区，**最终仍手动成交**。
12. **异常人物识别：**提示通缉、隐蔽通缉与仿生人（Aug）标记，包含伪装者；普通商人身份不提醒，可关闭自动通知。
13. **快捷键自定义：**设置其它按键或 Ctrl/Alt/Shift 组合，重启保留，可恢复默认 F4。

## 相对 V1.3 的累计更新

相对 V1.3，V1.9.4 累计新增：扩展物品目录及价值/体积排序、水管理、基础补齐与推荐机器装配、顾客需求备货、异常人物识别、库存删除。

选好目标和参数后，点击操作按钮直接执行，不再要求先预览、再二次确认。内部身份、归属、容量和重复操作检查保留；V1.9.4 同时将交易揭露检查更新为点击执行时重新核验。
