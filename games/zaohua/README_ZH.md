## 功能

- **alpha.52新增：**一键添加95种极品永久属性丹，每种100颗，共9500颗。包括速度、攻防、气血、护甲／护罩、八灵根、修炼效率、丹田、神魂、气运和寿元；不含血煞丹。仅添加到背包，不自动服用或改耐药。没有极品版本及临时恢复丹不纳入；单项数量框不影响套装，每点击一次再加一套。

- **物品添加：**分类、品阶查找并添加物品；一键添加常规突破套装，共10种18件，不含血道丹，不自动服用或突破。
- **灵石与主角：**自定义每次增减1～1亿灵石；调整主角属性及炼丹、制符、炼器经验或等级。
- **NPC与地图：**查询位置、修改好感、同地图传送、揭开当前地图迷雾；支持的普通大地图可用左Alt＋左键瞬移。
- **丹田方案：**扩展格子和功法数量；布局导入导出、一键补学与融合、按预设装备丹田及术法栏，并可逐个删除方案。
- **战斗辅助：**按设定顺序出招，主角空闲回合恢复气血；保留原生精力、冷却和次数限制。
- **炼器参考：**按装备原有用途生成参考配方，不直接生成定制装备。

## 使用

1. 正常保存并退出游戏，备份存档和已有MOD。
2. 解压到 `Zaohua.exe` 所在目录，让 `BepInEx` 与游戏程序同级。已有其它加载器或同名 `winhttp.dll` 时，先核对兼容，不要直接覆盖。
3. 进入存档，停下移动、关闭其它游戏面板，按**反引号键（1左侧、Esc下方，不按Shift）**开关菜单，也可在菜单中自定义。

修改后正常保存。一键套用布局前先存档；布局备份不能撤销全部学习、融合或属性变化。出现“结果待核对”时，先检查实际状态，不要连续重复点击。仅卸载修改器时，退出游戏后移除 `BepInEx/plugins/ZaohuaTrainer`；其它MOD仍在使用的加载器应保留。
